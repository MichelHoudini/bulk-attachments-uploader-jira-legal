Bulk Attachments Uploader for Jira

Support

For help with installation, file mapping, upload results, or a reproducible defect, email algomind.atelier@gmail.com.

What to include

Please include the Jira site URL, the approximate time of the problem, non-sensitive error text, and steps to reproduce it. Do not send attachments, Jira API tokens, passwords, or other credentials by email.

What the app supports

The app maps local files using a CSV or Jira issue keys in filenames, validates the target issues available to the current user, uploads each file as a native Jira attachment, and reports each result.
